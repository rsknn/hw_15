# Условие задачи

С одномерным массивом из `N` вводимых с клавиатуры положительных и отрицательных целых чисел выполнить вычисление (Вариант 7): найти **количество элементов массива, расположенных до минимального элемента**.

# 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**.
2. **Заполнение массива:** последовательный ввод `N` (`10`) целых чисел `A[i]` в цикле `for` (`i` от `0` до `N - 1`) с проверкой корректности ввода.
3. **Инициализация минимума:** `min_val = A[0]`, `min_idx = 0`.
4. **Поиск минимального элемента (цикл `for` для `i` от `1` до `N - 1`):**
   * Если `A[i] < min_val`, обновить `min_val = A[i]` и запомнить позицию `min_idx = i`.
5. **Вывод результата:** печать минимального значения `min_val` и количества элементов до него, равного `min_idx`.
6. **Конец**.

# 2. Реализация программы

```c
#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <locale.h>
#define N 10

int main() {
    setlocale(LC_CTYPE, "RUS");
    int A[N];
    printf("Введите %d целых чисел:\n", N);
    for (int i = 0; i < N; i++) {
        printf("A[%d] = ", i);
        scanf("%d", &A[i]);
    }
    int min_val = A[0];
    int min_idx = 0;
    for (int i = 1; i < N; i++) {
        if (A[i] < min_val) {
            min_val = A[i];
            min_idx = i;
        }
    }
    printf("\nМинимальный элемент массива: %d (индекс %d)\n", min_val, min_idx);
    printf("Количество элементов до минимального: %d\n", min_idx);
    return 0;
}
```
